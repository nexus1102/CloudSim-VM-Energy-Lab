# 第三轮阶段3：独立数据包

完整原始运行采用SHA256内容寻址去重；manifest记录每个路径、原字节长度与哈希，ZIP只存每种内容一次，不删减仿真数据或替换历史来源。restore_data.py创建全新目录，先验证所有blob再重建，拒绝覆盖、重复名、绝对路径、路径越界和保留名冲突。
verify_dataset.py支持矩阵或研究两类独立核验，旧绝对输入路径由冻结来源解析，不修改原件。研究预算使用临时分析配置定位还原输入，原配置保留原字节；配对区间在临时目录复算对照。所有核验仅需Python，JDK只用于重新仿真。
测试：重复内容无损还原、hash损坏拒绝、路径越界拒绝；真实完整矩阵数据包约47MB，文件8064、唯一内容3064，还原核验另记录实际结果。
九维审阅覆盖隐藏BUG、边界、性能、安全、重复、维护、扩展、异常和提示。修复保留cache/manifest名称可覆盖中间数据的风险，限制源label及symlink；原始公开数据包不含Git凭据或.git。
