# 物理假设与论文依据

本文件区分论文明确描述、公开CloudSim实现及工程重建。参数合理性可以通过容量与能量约束检验，但不能证明其等于作者未公开参数。模型及规则的变化必须作为新实验条件报告。

| 项目 | 当前实现 | 依据与判断 |
|---|---|---|
| 平台层级 | ResearchDatacenter继承PowerDatacenter；ResearchPolicy提供策略接口；ResearchConfig与UPS损耗联动 | 对应论文图2-12、2-13的供电感知数据中心、放置接口、GetHostPower和UPS模型功能；不是只在仿真结束后乘损耗系数 |
| 场景 | 100服务器、5机架；实际VM/Cloudlet一对一 | 前两项来自正文；公开PlanetLab替代作者缺失一天数据，输入及出处均存档 |
| 服务器功率 | 有驻留VM的Host采用218.3+131.7u W；空Host关机 | 线性功率端点来自正文；关机处理及零CPU驻留Host区别必须显式保持 |
| CPU资源 | 每Host一个聚合PE，2500MIPS；VM分档2500/2000/1000/500MIPS | 工程选择，不能把作者运行仿真的i5/8GB电脑当成模拟服务器配置 |
| VM其他资源 | RAM512MB、BW1000kbps、镜像1000MB；Host64GB/1Gbps/1TB | 工程选择；CPU均值与MIPS加权Host负载不是同一分母 |
| UPS模块 | N=4，模块2kW，可用输出7.5kW/机架 | N及额定值为重建；20台Host满载7kW，20W/端点附加场景的保守端点预算0.4kW仍低于7.5kW；7.5kW不超过N模块8kW |
| N+1拓扑 | 默认N模块负载均分，另一个备用模块损耗单列；另测N+1全模块均担 | 备用角色来自论文；备用功率0W是理想下界，20W敏感性场景为假设 |
| 2N拓扑 | 两套N模块共同均担负载，任一套容量满足可用输出 | 正常工况均担重建；未模拟故障切换动态 |
| UPS损耗命名 | quadratic、linear、constant明确对应多项式阶次 | 避免a0/a2习惯与字面论文公式混淆；聚合系数由模块配置推导，不使用固定UPS倍数代替模块物理意义 |
| DC主曲线 | 0.0549x²+0.0077x+0.0207（额定功率归一化） | 既有曲线重建；与字面式系数0.0241x²+0.0353x+0.0617分支独立保存，后者与图2-17矛盾未消除 |
| AC静态曲线 | 0.0376x²+0.0069x+0.0319 | 既有AC曲线重建，用于明确声明的架构对照 |
| 初始容量 | 主cap=0.9，同时实验cap=1.0 | 图2-9分组与0.9一致，但只能支持一个容量区间；不是全章统一0.9的唯一证明 |
| BFD-GA | BFD固定VM分组，GA基因是启用服务器对应机架 | 符合两步降维思路；轮盘选择、交叉、变异的具体工程实现仍非作者源码 |
| GA/GGA | 默认仅服务器功率目标、随机Host初始化及资源修复；另测试可行打包初始化/总功率目标 | 区分传统VM→Host搜索与BFD-GA的Host→Rack搜索；GGA组算子仍为重建，没有凭排名反向调参 |
| 动态过载 | CPU>90%随机选择一驻留VM；真实迁移事件 | 论文明确描述；目的节点默认调用公开CloudSim最小新增服务器功率寻找器，不能宣称作者采用同一目的算法 |
| 轻载规则 | 默认<30%连续3次、冷却900秒，尝试整机撤空；另设threshold仅过载对照 | 为防止随机初始铺开持续空载而补充的工程控制；作者完整轻载规则未确认；没有周期性全局重放置 |
| 迁移复制 | 半NIC吞吐、源CPU服务90%、目的复制10%；两端可用BW守卫 | 公开CloudSim执行约定及工程边界；副本不重复执行工作量 |
| 附加迁移功率 | 默认每端点0W，另实验20W；加到实际机架输出再算UPS | 0W仅是未测定增量的下界，复制CPU能耗已有计入；20W不是实测结果 |
| 数值保护 | 仅距整数≤1e-8MIPS的请求吸附到整数，可配置为0关闭 | 原生超分配Math.floor对微小浮点超容量敏感；不修改原CPU数据、不修改CloudSim内核，回归验证实际工作量 |
| 费用 | 年度能耗仅按100服务器模型及表2-1占比条件推算 | 产业总电费、费率、统计规模不明，不能直接证明原文年度成本数字 |

未完成的作者唯一细节包括GGA具体算子、迁移完整控制规则、硬件档次、UPS待机参数、遗传停止判据及成本统计口径。当前平台将这些项公开配置化，具备声明条件下的实际运行与核验能力，适合创新算法对照。

主动态三种子BFD-GA均值约184.404kWh，正文184.98kWh基准偏差约−0.31%；图像估计约154.536kWh基准偏差约+19.32%。这说明正文数值接近而图像比较仍超过15%容差，不可称两项均满足。GGA/BFD等完整排名及图2-26停止速度结论亦尚未恢复。

尚未建模脏页多轮复制、停机时间、交换机独立耗电、UPS切换瞬态与故障概率。后续涉及这些因素的创新，应扩展状态与核算边界，并使用新实验目录保存新版本。
